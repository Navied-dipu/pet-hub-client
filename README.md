# 🐾 Pet Adoption Platform

A full-stack **Pet Adoption Web Application** built using **Next.js**, **DaisyUI**, **HeroUI**, and **React Icons**.  
This platform allows users to browse pets, view details, and manage adoption requests through a clean and responsive UI.

---

## 🚀 Live Demo

🔗 Live URL: https://pet-hub-client-three.vercel.app

---

## 📌 Project Purpose

This project simulates a real-world pet adoption system where:

- Users can explore available pets (dogs, cats, birds, etc.)
- Users can view detailed pet profiles
- Authenticated users can send adoption requests
- Pet owners can manage pet listings and requests

---

## ✨ Features

- 🔐 User Authentication (Login / Register)
- 🐶 Browse All Available Pets
- 📄 Pet Details Page
- 📝 Adoption Request System
- 🧑‍💼 User & Owner Dashboard
- ➕ Add / Edit / Delete Pets
- 📊 Manage Adoption Requests (Approve / Reject)
- 🔎 Search & Filter Pets (name, species)
- 📱 Fully Responsive Design
- 🔔 Toast Notifications for actions
- ⚡ Optimized Next.js Routing
